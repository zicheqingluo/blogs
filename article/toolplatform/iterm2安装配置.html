    # 安装主题

    Settings → Profiles → Colors
→ Color Presets... → Import
→ 选择下载的 .itermcolors 文件
→ 再次点击 Color Presets... 选择刚导入的主题

针对 Claude Code 最推荐
第一名：Dracula
![最适合看代码输出]

Settings → Profiles → Colors → Color Presets
→ 搜索 Dracula
Claude Code 的绿色成功/红色报错，在 Dracula 下对比度极佳

第二名：One Dark
和 VS Code 默认主题一致，眼睛有记忆感，切换不累

第三名：Solarized Dark
iTerm2 内置自带，不用下载，直接选

⚙️ 顺手再调这几个参数
Profiles → Window
├── Transparency：10%（微透明）
└── Blur：勾选，Radius 10

Profiles → Text  
├── Font：MesloLGS NF 13px（支持图标）

Profiles → Terminal
└── Scrollback lines：10000（Claude 输出很长）
